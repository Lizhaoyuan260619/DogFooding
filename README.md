# DogFooding

> Solo Coder 做题统一仓库。所有项目的代码都在此仓库内，按项目编号分文件夹管理。

## 目录结构

```
DogFooding/
├── projects/          # 项目目录（每题一个文件夹，格式：lzy-00XXX）
│   ├── lzy-00021/
│   ├── lzy-00022/
│   └── ...
└── task记录表.xlsx    # 做题记录表
```

## 多电脑协作规则

1. 做题前先 `git pull origin main` 同步
2. 每个人只在自己负责的项目文件夹内工作
3. 做完 `git add projects/lzy-00XXX/` + `commit` + `push`
