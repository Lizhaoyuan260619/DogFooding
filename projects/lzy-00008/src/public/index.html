📘 CryptoVault 使用说明

CryptoVault 是一款基于 Node.js 的轻量化加密通信工具，提供密钥管理、加密/解密、数字签名和安全删除等功能。本页介绍常用操作流程。

🚀 快速上手指引
① 生成密钥对
进入"密钥管理"页，填写密钥名称和密码，点击"生成密钥对"。密钥指纹是您的身份唯一标识。
② 添加联系人
进入"联系人"页，添加联系人昵称和对应的公钥文件路径。之后加密时可直接用昵称选择接收方。
③ 加密一条消息
进入"加密消息"页，输入消息内容和接收方（昵称或公钥路径）。可选填发送方密钥用于签名。
④ 解密一条消息
进入"解密消息"页，输入加密文件路径、密钥名称和密码，即可恢复明文。若附有签名会一并校验。
🎯 命令面板 (Ctrl+K) 使用

在任意页面按 Ctrl+K 打开命令面板：

⌨ 输入关键字：encrypt / 加密 / 密钥 / sign
⌨ ↑/↓ 选择，Enter 执行
⌨ Esc 关闭

支持跳转页面、导出密钥、初始化数据库等常用操作。比传统 CLI 命令行更快、更直观。

🛡️ 安全提示

• 私钥密码请妥善保管，丢失后无法找回。

• 安全删除功能会覆写文件 3 次，操作不可逆。

• 加密通信前，请确保已获取接收方的公钥文件。

• 建议定期导出密钥对备份，并离线保存。

📞 遇到问题？

• 检查页面底部状态栏是否显示"已连接"。

• 查看右侧 Toast 提示的错误信息，通常会直接告诉你原因。

• 刷新页面，或点击右上角"初始化数据库"重置本地数据。

• 查看"快捷键"页获取全部键盘操作列表。
