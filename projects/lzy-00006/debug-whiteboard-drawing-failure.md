### 根本原因 (Root Cause)

**代码中引用了未定义的 `VoiceClient` 类，且 `voice-client.js` 文件不存在。**

**错误链路：**
1. `initSocket()` 调用 `initVoice()`
2. `initVoice()` 第567行执行 `new VoiceClient(socketClient.socket)`
3. 抛出 `ReferenceError: VoiceClient is not defined`
4. 异常被 `initApp()` 的 try-catch 捕获
5. `initApp()` 提前终止，未执行后续的 `initUIEventBindings()` 和 `loadInitialData()`

**后果：**
- UI 事件绑定未完成（工具按钮、撤销/重做按钮等）
- 初始数据未加载
- 绘图功能完全失效
- 服务看起来"不可用"因为页面功能不完整
