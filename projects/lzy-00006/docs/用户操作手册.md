# 实时语音对讲功能 用户操作手册

## 1. 功能概述

实时语音对讲功能使团队成员能够在协作画板中进行即时语音沟通，无需切换到外部聊天工具，提升协作效率。

## 2. 快速开始

### 2.1 加入语音对讲

1. 进入协作画板房间
2. 在右侧面板找到「语音对讲」区域
3. 点击「加入语音」按钮
4. 首次使用时，浏览器会请求麦克风权限，请点击「允许」

> **提示**：加入语音的操作仅需 **1 步**（点击按钮 + 授权）

### 2.2 离开语音对讲

点击语音面板右侧的「挂断」按钮即可离开语音对讲。

## 4. 操作指南

### 4.1 静音/取消静音

- **方法一**：点击「静音」按钮
- **方法二**：使用快捷键 `Ctrl + M` (Windows) / `Cmd + M` (Mac)

静音后，其他参与者将听不到您的声音，但您仍能听到其他人的声音。

### 4.2 按键说话 (PTT)

按住「按住说话」按钮时说话，松开按钮后自动静音。适合需要精确控制发言时机的场景。

- 支持鼠标操作：按住鼠标左键
- 支持触摸操作：按住按钮
- 支持键盘快捷键：按住 `空格键`

### 4.3 管理员操作

**第一个加入语音的用户自动成为管理员**，拥有以下权限：

1. **全体静音**：点击「全体静音」按钮可将除自己外的所有参与者静音
2. **单独静音**：点击参与者列表中的某位用户，可单独将其静音/取消静音
3. **管理员移交**：当管理员离开语音时，系统自动将管理员权限移交给最早加入的用户

### 4.4 查看参与者状态

语音面板底部显示当前所有语音参与者列表：

- **讲话中**：绿色闪烁圆点 + "讲话中" 文字
- **静音**：红色圆点 + "静音" 文字
- **空闲**：灰色圆点 + "空闲" 文字
- **管理员标识**：用户名后显示黄色"管理员"标签

## 5. 常见问题

### 5.1 浏览器提示"麦克风权限被拒绝"

**解决方案**：
1. 点击浏览器地址栏左侧的 🔒 图标
2. 找到「麦克风」权限设置
3. 选择「允许」
4. 刷新页面后重新加入语音

### 5.2 听不到其他人的声音

**排查步骤**：
1. 检查系统音量是否开启
2. 检查浏览器标签页是否被静音（右键标签页 → 取消静音）
3. 确认其他参与者是否处于静音状态
4. 尝试切换音频输出设备

### 5.3 其他人听不到我的声音

**排查步骤**：
1. 检查是否已静音（静音按钮显示"解除静音"表示当前已静音）
2. 检查麦克风是否被其他应用占用
3. 确认浏览器麦克风权限已允许
4. 尝试离开后重新加入语音

### 5.4 语音卡顿或延迟高

**可能原因及解决方案**：
1. **网络问题**：检查网络连接，尝试切换到更稳定的网络
2. **带宽不足**：关闭其他占用带宽的应用
3. **系统资源不足**：关闭不必要的浏览器标签页和应用程序
4. **设备性能问题**：降低语音质量（系统会自动调整）

> 系统具备**自适应码率调整**功能，会根据网络状况自动优化语音质量。

### 5.5 有回声或噪声

**解决方案**：
1. 请使用耳机，避免扬声器声音被麦克风拾取
2. 确保只有一个设备加入语音（避免同一房间多设备同时开启）
3. 检查是否有其他参与者未静音且环境嘈杂
4. 系统已启用回声消除和噪声抑制，如仍有问题可尝试重新加入

## 6. 隐私与安全

### 6.1 数据隐私

- **不存储语音内容**：所有语音通话仅在参与者之间实时传输，服务器不存储任何语音数据
- **端到端加密**：语音数据采用 DTLS-SRTP 协议加密传输
- **无需注册额外账号**：使用现有协作系统账号即可

### 6.2 隐私设置

- 您可以随时开启/关闭语音功能
- 您可以随时拒绝麦克风权限（但将无法使用语音功能）
- 静音状态下，系统不会采集任何音频数据

## 7. 快捷键

| 快捷键 | 功能 | 平台 |
|--------|------|------|
| `Ctrl + M` / `Cmd + M` | 切换静音 | 全部 |
| `空格键`（按住） | 按键说话 | 全部 |
| `Esc` | 离开语音对讲 | 全部 |

## 8. 使用建议

### 8.1 会议礼仪

1. 加入语音后建议先静音，需要发言时再解除静音
2. 发言前请先说明身份（如："我是张三，我说一下..."）
3. 多人同时发言时请互相礼让
4. 长时间不发言时建议静音，减少背景噪声干扰

### 8.2 性能优化

1. 语音会话期间避免打开过多占用资源的应用
2. 建议使用有线网络或优质 WiFi
3. 使用耳机可获得更好的音频质量
4. 移动设备使用时建议保持电量充足
