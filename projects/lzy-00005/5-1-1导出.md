**User**

从零构建一个基于 Zettelkasten 方法论的个人知识管理Web应用，后端 Python Flask + SQLite，前端原生 HTML/CSS/JS。核心功能包括：笔记编辑：支持 Markdown 编写，每条笔记有唯一 ID、标题、正文、标签、创建/修改时间；双向链接：在正文中使用  [[笔记ID]]  语法自动创建笔记间引用关系，笔记底部展示所有反向链接列表；知识图谱可视化：用 Canvas 绘制笔记节点和引用关系的有向图，支持拖拽节点、缩放画布、点击节点跳转；全文搜索：对标题和正文做模糊搜索，高亮匹配关键词；标签聚合：按标签查看所有关联笔记；导出：支持将笔记及其所有双向链接递归导出为单个 Markdown 文件（保持引用关系）。后端必须采用 Blueprint 模块化架构：notes、graph、search、export 四个 Blueprint，各自有独立的 routes/services/models。图谱可视化算法必须封装到独立文件 static/js/graph-renderer.js，主页面 JS 只负责调用，不允许把 Canvas 绘制逻辑散落在 HTML 中。图谱节点布局必须使用力导向算法（Force-directed layout），不允许固定坐标。数据库访问层统一封装在 models/ 目录，使用 Repository 模式，路由文件中不允许出现 SQL 语句。全文搜索不允许引入 Elasticsearch/Whoosh 等外部搜索服务，必须用 SQLite FTS5 实现全文索引。前端必须使用 ES6 模块，API 调用封装到 api.js 单独模块。

### 📁 项目结构

```
lzy-00005/
├── app.py                              # Flask 应用入口
├── requirements.txt                    # 依赖（Flask + Markdown）
├── models/                             # Repository 模式数据层
│   ├── database.py                     # SQLite 连接管理 + FTS5 初始化
│   ├── note_repository.py              # 笔记数据访问
│   ├── tag_repository.py               # 标签数据访问
│   └── link_repository.py              # 双向链接数据访问
├── blueprints/                         # Blueprint 模块化架构
│   ├── notes/                          # 笔记 CRUD + 双向链接 + 标签
│   │   ├── routes.py, services.py
│   ├── graph/                          # 知识图谱数据
│   │   ├── routes.py, services.py
│   ├── search/                         # SQLite FTS5 全文搜索
│   │   ├── routes.py, services.py
│   └── export/                         # 递归导出 Markdown
│       ├── routes.py, services.py
├── templates/
│   └── index.html                      # 主页面
└── static/
    ├── css/style.css                   # Apple HIG 风格样式
    └── js/
        ├── api.js                      # ES6 模块 API 封装
        ├── graph-renderer.js           # Canvas 力导向图谱可视化（独立文件）
        └── main.js                     # 主交互逻辑
```

### 🎯 已实现的核心功能

| 功能 | 状态 | 技术实现 |
|------|------|----------|
| **笔记编辑** | ✅ | Markdown 编写，唯一 ID、标题、正文、标签、创建/修改时间 |
| **双向链接** | ✅ | `[[笔记ID]]` 语法自动解析，反向链接列表展示 |
| **知识图谱** | ✅ | Canvas 力导向算法，支持节点拖拽、滚轮缩放、点击跳转 |
| **全文搜索** | ✅ | SQLite FTS5 + trigram tokenizer，支持中文搜索，结果高亮 |
| **标签聚合** | ✅ | 按标签筛选笔记，标签计数展示 |
| **Markdown 导出** | ✅ | 递归导出所有关联笔记为单个 .md 文件，保持引用关系 |

### 🏗️ 架构亮点

1. **后端 Blueprint 模块化**：notes / graph / search / export 四个独立蓝图，各自有 routes + services
2. **Repository 模式**：所有 SQL 封装在 `models/` 目录下，路由层零 SQL
3. **FTS5 全文索引**：使用 trigram tokenizer 支持中文模糊搜索
4. **图谱独立封装**：`graph-renderer.js` 封装力导向算法，主页面仅调用 API
5. **ES6 模块化**：`api.js` 单独封装所有请求，前端代码解耦

```bash
pip install -r requirements.txt
python app.py
```

访问 **http://127.0.0.1:5000** 即可使用。应用已在后台运行，你可以直接在浏览器中体验所有功能！
